Privacy Policy

Last updated: November 19, 2026

Oto Yukleme is a personal tool used only by its owner to upload the owner's own videos to the owner's own YouTube channels and Instagram accounts.

Data we access

With the owner's permission, the tool uses the YouTube Data API (scope: youtube.upload) and the Instagram API only to upload videos, titles and descriptions. It does not read, collect or store data about any other person.

Storage

Access tokens are stored as encrypted secrets in the owner's GitHub repository and are used only to perform uploads. No data is sold or shared with third parties.

YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.
